# 初版の検証記録

検証日: 2026-10-25（日本時間）

## 環境と自動検証

- Apple M3 Max / arm64、macOS 26.6.2、Xcode 26.6。
- 対応基準はmacOS 26系、deployment targetは26.0。実機確認の基準はmacOS 26.6.2とし、旧世代macOSへの対応は対象外。
- `./scripts/build.sh`: Releaseビルド成功、arm64 `.app` 生成、署名検証成功。
- 最終アプリのビルド成功後、ビルドスクリプトに実行中チェック、任意の署名指定、起動先の登録処理を追加した。この最終スクリプトでのフル再ビルドは未実行。構文検査、実行中の停止ガード、限定した起動先登録は確認済み。許可済みバイナリを維持するため再ビルドしていない。
- `./scripts/test.sh`: 12件成功、失敗0。ホストレスXCTestで実際の幾何・設定・フレーム保持のソースをコンパイル。
- テスト範囲: 縦横比と中央配置、空入力、画面外・巨大ウィンドウの補正、負座標の画面、小さい指定倍率の維持、設定の保存形式と無効値補正、旧ストリームの遅延フレーム拒否。
- Metalシェーダーは同梱テキストを起動時に標準APIでコンパイルする。追加のMetal Toolchainや外部ライブラリは不要。
- ビルド・テストのログとxcresultは `build/` 内のローカル成果物で、リポジトリには含めない。

## GUI・実フレーム確認

- 内蔵Retina画面: 4112×2658の実フレームを取得。
- 外部HDMI画面: 1920×1080の実フレームを取得し、ウィンドウで目視確認。
- 内蔵／外部の選択切り替え、再試行、30／60 FPS・システム上限の設定操作を確認。
- カーソルON／OFFでストリーム再開と実フレームの継続を確認。すべてのカーソル形状を網羅した目視試験ではない。
- 50／100／200％、縦横比調整、最前面切り替え、標準全画面への移行と復帰を確認。
- 1920×1080映像の50％ではウィンドウ480×302ポイント、100％では960×572ポイント。表示先は2倍Retinaで、各高さにはタイトルバー32ポイントを含む。
- 自アプリの取得除外を目視確認。再帰するビューアー映像は現れていない。
- 通常終了・再起動後、外部画面の取得が再開。表示対象UUID、ウィンドウ位置・サイズ、FPS、カーソル、最前面の保存値が再起動前と一致。
- 最終確認では `dist/ExMonitorViewerMac.app` のプロセス1つだけが実行されていた。
- 個人のデスクトップ画像は保存・登録していない。画面内容・他アプリのタイトルはアプリログに記録しない。

## 権限の問題と復旧

開発中にad-hoc署名の再ビルドで署名ハッシュが変わり、画面収録設定がONでも取得が拒否された。macOSの権限ログに、保存済みコード要件と現在の署名が一致しない記録があった。OFF→ONだけでは復旧しなかった。

ビルド先と `dist` のコピーを両方終了し、ユーザーの明示承認を得て `tccutil reset ScreenCapture com.zabaglione.ExMonitorViewerMac` を一度実行。現在の `dist` アプリを設定へ新規追加してユーザーが許可した後、取得・再起動とも成功した。ほかのアプリや権限はリセットしていない。

Developer ID署名は実行していない。最終アプリは元の計画どおりad-hoc署名で、公証・公開配布は未実施。

## レビューと残る確認範囲

Astraで実装をレビューし、旧ストリームのフレーム混入と小さい倍率の強制拡大を修正。追加した2件の回帰テストを含め12件が成功し、修正の再レビューで重大な追加指摘はなかった。

外部画面の物理的な抜き差し、実機での解像度変更、Intel、HDR、実際の走査出力FPS・遅延・長時間負荷は未検証。FPSの設定値は取得・描画の上限であり、実測FPSを保証するものではない。Webex固有の挙動は検証対象外。

## 対応基準の変更

ユーザー指定により、対応基準を現在のmacOS 26系（実機26.6.2）に統一した。アプリ・テストの全構成でdeployment targetを26.0へ変更。起動中アプリの署名と画面収録許可を維持するため、変更後のビルドは別の検証用生成先で確認し、`dist`のアプリは置換していない。上記GUI・実フレームの証拠は初版アプリによるもの。

変更後の確認: 別生成先へのReleaseビルド（未署名）が成功し、生成したInfo.plistの最低OSが26.0、実行形式がarm64であることを確認した。macOS 26.6.2で単体テスト12件が再び成功した。検証用アプリは起動候補から外し、`dist`だけを起動先に登録し直した。
