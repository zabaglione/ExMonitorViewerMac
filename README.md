# ExMonitorViewerMac

Macの別の画面を、手元のウィンドウに表示するアプリです。外部モニターに出している内容を、手元の画面で確認できます。

## できること

- 表示したいディスプレイを選び、映像を拡大・縮小して確認できます。
- ウィンドウを最前面に置いたり、全画面に切り替えたりできます。
- カーソルの表示と、映像の更新頻度を切り替えられます。
- 表示対象やウィンドウの位置・サイズなどを、次回起動時に復元します。

映像を見るためのアプリです。表示した映像へのクリック・キー入力の転送、動画や音声の録画・録音は行いません。

## 動作環境

- Apple Silicon搭載Mac
- macOS 26以降（実機確認：macOS 26.6.2）
- macOSの画面収録許可

外部モニターを表示する場合は、macOSのディスプレイ設定で画面を拡張してください。内蔵ディスプレイだけでも使えます。このアプリ自身のウィンドウは取得映像から除外されます。

## 入手と初回起動

[最新版をダウンロード（DMG）](https://github.com/zabaglione/ExMonitorViewerMac/releases/latest)

Apple Silicon向けのDMGを配布しています。アプリはDeveloper ID署名・Apple公証済みです。ソースから利用する場合は[ビルド手順](docs/development.md)を参照してください。

### アプリをインストールして開く

1. 入手したDMGを開き、`ExMonitorViewerMac.app`を`Applications`へドラッグします。
2. 「アプリケーション」フォルダーからExMonitorViewerMacを開きます。
3. インターネットからダウンロードしたアプリを開いてよいか確認されたら、入手元とアプリ名を確認して「開く」を選びます。

### 画面収録を許可する

1. アプリ内の`Open Screen Recording Settings`を選びます。
2. システム設定の「プライバシーとセキュリティ」→「画面収録とシステムオーディオ録音」で、ExMonitorViewerMacを許可します。
3. macOSから終了・再起動を求められた場合は、その案内に従います。アプリを開き直し、必要なら`Capture > Retry Capture`を選びます。
4. `Display`メニューから表示したい画面を選びます。初回は、メイン画面以外のディスプレイを優先して選択します。

アプリを開く確認と画面収録の許可は別の操作です。画面収録を許可するまで、映像は表示されません。このアプリは画面をウィンドウに表示するために許可を使い、動画ファイルには保存しません。

### 起動がブロックされた場合

公式配布版は署名・公証済みのため、通常は上記の「開く」の確認で起動できます。「開発元を確認できない」「壊れている」「コンピュータに損害を与える」などの警告が出た場合は開かず、公式リリースから取り直してください。改善しない場合は、表示された警告とmacOSのバージョンを[Issues](https://github.com/zabaglione/ExMonitorViewerMac/issues)へお知らせください。画面内容などの個人情報は添付しないでください。

詳しくは[Appleの案内](https://support.apple.com/ja-jp/102445)を参照してください。macOS全体のセキュリティ機能を無効にする必要はありません。

## 操作

| メニュー | 操作 |
| --- | --- |
| `Display` | 表示元のディスプレイを選びます。 |
| `View > Fit Window to Image`（⌘F） | ウィンドウを映像と同じ縦横比に合わせます。 |
| `View > Scale` | 50％・100％・200％のサイズを選びます。Retinaの表示倍率を考慮し、画面内に収まる大きさに調整します。 |
| `View > Always on Top` | 最前面表示を切り替えます。 |
| `View > Enter Full Screen`（⌃⌘F） | 全画面表示に切り替えます。同じ操作で元に戻せます。 |
| `Capture > 30 FPS / 60 FPS / System Maximum` | 映像の更新頻度の上限を選びます。実際の速度は画面の更新頻度やMacの負荷によって変わります。 |
| `Capture > Show Cursor` | 取得映像のカーソル表示を切り替えます。 |
| `Capture > Retry Capture`（⌘R） | 画面の取得をやり直します。 |

## アップデート

`ExMonitorViewerMac > Check for Updates...`で新版を確認できます。新版が見つかったら内容を確認し、`Install Update`を選びます。準備が完了したら`Install and Relaunch`で更新・再起動します。キャンセルした場合は現在のアプリを使い続けられます。

`Automatically Check for Updates`で自動確認を切り替えられます。インストールは毎回確認します。更新は署名を検証し、確認できないファイルはインストールしません。

接続エラーは「最新版」という意味ではありません。ネット接続を確認して再試行するか、[公式リリース](https://github.com/zabaglione/ExMonitorViewerMac/releases/latest)から最新版を入手してください。

## 映像が表示されないとき

- `Display`メニューで表示元を選び直し、`Capture > Retry Capture`を選んでください。
- 外部モニターの電源・接続と、macOSのディスプレイ設定を確認してください。
- `Capture > Open Screen Recording Settings`から、このアプリの画面収録許可を確認してください。

許可済みでも表示されない場合は、アプリを終了し、画面収録設定からこのアプリの項目だけを削除します。その後、現在使っているアプリを追加して許可し、開き直してください。ほかのアプリの許可を変更する必要はありません。
